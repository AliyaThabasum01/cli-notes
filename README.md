# 📝 CLI Notes

A lightweight command-line notes application built with Python.

## Features

- Add notes
- View saved notes
- Store notes locally
- JSON-based storage
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
========================================
📝 CLI Notes
========================================

1. Add note
2. View notes
3. Exit

Choose an option: 1
Enter your note: Finish today's project

✅ Note saved.
```

## Built With

- Python
- JSON
- Standard Library
